# MARIO TENNIS 64 - WEB PORT & NETPLAY

Port web y sistema de multijugador online para **Mario Tennis (Nintendo 64)** en el navegador.

## 🎾 Características
- **Emulación N64 WebAssembly**: Motor optimizado Mupen64Plus para navegadores modernos.
- **Multijugador Online (Netplay Peer-to-Peer)**: Juega con otra persona por internet usando WebRTC con latencia ultra-baja.
- **Soporte de Mandos y Gamepads**: Conecta mandos de Xbox, PlayStation, Nintendo Switch o genéricos vía Gamepad API.
- **Controles Táctiles y Teclado**: Soporte para teclado configurable y controles virtuales en pantalla.
- **Sin necesidad de instalar nada**: Ejecución 100% nativa en el navegador cliente.
